Interprete desarrollado en base al archivo guía de la clase 17 y demás archivos proporcionados en todas las clases.
Se hace uso de IA para fortalecer conocimientos, conceptos o errores que no se lograban entender. Todas las funcionalidades
se hizo prueba de concepto, se integraron y se verificaron manualmente dentro del interprete.


El interprete cuenta con los siguientes puntos según el proyecto:


- Valores denotados
- Valores expresados
- Identificadores
- Variables y asignación
- Primitivas: booleanas, aritméticas, cadenas, listas, diccionarios, control y recursión
- Estructuras de control
- Ciclos 
- Invocación de funciones
- Expresiones simbólicas
- Nuevas funciones primitivas: Simplificar y evaluar
- Listas dinámicas
- Diccionarios


Al final del archivo se agrupan algunas de las pruebas realizadas durante el desarrollo del proyecto. 
Estas pueden ejecutarse desde la consola (REPL) de DrRacket una vez compilado el intérprete.
